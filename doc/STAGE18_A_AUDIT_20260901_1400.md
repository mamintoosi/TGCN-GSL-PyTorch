## 5. Current Graph Construction Pipeline

### DAGMA → Adjacency (from graph_utils.py)

```python
def build_gsl_adjacency(W_est, w_threshold=0.3):
    if W_est.ndim == 3:
        W_est = np.any(W_est > 0, axis=2)  # Union across PHs
    adj = np.zeros(W_est.shape, dtype=np.float32)
    adj[W_est > 0] = 1.0  # Binary
    return adj
```

### GCN normalization (from graph_conv.py)

```python
A_tilde = adj + torch.eye(N)  # Self-loops
D_inv_sqrt = diag(row_sum(A_tilde)^{-0.5})
normalized = D_inv_sqrt @ A_tilde @ D_inv_sqrt  # Symmetric normalization
```

### Key properties:
- Binary graph (weight magnitudes discarded)
- Self-loops added
- Symmetric normalization D^{-1/2}(A+I)D^{-1/2}
- Same normalization applied to all graph types (fair comparison)

## 7. Hybrid Graph Construction Strategies

### Strategy B1: DAGMA ∪ Physical (controlled budget)
Take DAGMA's 8 edges + top-K physical edges to reach a target budget (e.g., 16, 24, 32 total edges).

### Strategy B2: DAGMA ∪ Correlation (controlled budget)
Take DAGMA's 8 edges + top-K correlation edges to reach a target budget.

### Strategy B3: DAGMA ∩ Correlation
Keep only edges present in BOTH DAGMA and correlation graphs.

### Strategy B4: Score-level hybrid
Combine DAGMA weights with correlation coefficients into a single score, then sparsify.

### Strategy B5: DAGMA + physical neighbors of DAGMA hubs
Add the physical neighbors of DAGMA's active nodes to broaden spatial coverage.

### Strategy B6: DAGMA edges + their physical-path neighbors
For each DAGMA edge (i→j), also add physical-path neighbors of i and j.

## 8. Risks and Leakage Concerns

1. **Graph construction uses training data only** — This is correct and must be preserved.
2. **Correlation graph is built from training data** — No leakage.
3. **Physical graph is fixed (not data-dependent)** — No leakage.
4. **DAGMA graph is built from training data** — No leakage.
5. **Hybrid graphs must also use only training data** — Verify this.
6. **Edge budget matching is fair** — Compare at equal edge counts.
7. **Test set used only for final evaluation** — Verify no tuning on test RMSE.
